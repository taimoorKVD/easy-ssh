# Security Policy

## Supported versions

Only the [latest release](https://github.com/taimoorKVD/easy-ssh/releases/latest) is supported with security updates.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting.

1. Open this repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Fill in the details and submit the report.

Do not open a public issue or discuss an unfixed vulnerability in a pull request.

We will acknowledge your report and keep you informed as we investigate and ship a fix.
